# Website CV. Surya Mas Energy

Website company profile responsif dengan desain premium, warna navy dan emas. Menggunakan HTML, CSS, dan JavaScript statis, sehingga dapat dipublikasikan di layanan hosting gratis.

## File utama
- `index.html` — konten website
- `styles.css` — desain responsif
- `script.js` — kontak resmi dan menu mobile
- `assets/logo-placeholder.svg` — logo sementara, ganti dengan logo resmi
- `assets/favicon.svg` — ikon tab browser

## Sebelum dipublikasikan
1. Ganti `assets/logo-placeholder.svg` dengan logo resmi. Bila file logo bernama lain, ubah sumber gambar `assets/logo-placeholder.svg` pada dua tempat di `index.html` menjadi nama file yang benar.
2. Periksa kembali semua teks, terutama ejaan nama, legalitas, dan uraian layanan.
3. Bila tersedia, tambahkan foto proyek, sertifikasi, dan informasi legalitas yang boleh dipublikasikan.

## Publikasi gratis melalui Netlify
1. Ekstrak file ZIP ini di komputer.
2. Buka https://app.netlify.com/drop
3. Login atau buat akun Netlify.
4. Unggah folder hasil ekstrak yang berisi `index.html`, `styles.css`, `script.js`, dan folder `assets`.
5. Tunggu proses deploy selesai. Netlify akan memberikan URL situs dengan akhiran `netlify.app`.
6. Buka URL tersebut dan uji tampilan di HP/komputer, tombol WhatsApp, dan email.
7. Untuk pembaruan, unggah ulang folder yang telah diperbarui melalui halaman deploy situs Netlify Anda.

Alternatif hosting gratis:
- GitHub Pages: https://pages.github.com/
- Cloudflare Pages: https://pages.cloudflare.com/

## Catatan
Ini adalah website company profile statis. Tidak ada backend, database, login, atau formulir yang menyimpan data. Layanan ditulis berdasarkan informasi yang diberikan pemilik. Detail proyek dan persyaratan layanan tetap perlu dikonfirmasi dengan perusahaan.
